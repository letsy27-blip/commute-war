# 출근전쟁

모바일 테스트 APK 배포 저장소입니다.

## v1.49

- HP/SP 회복량 장비 옵션과 실제 휴식 회복 배율 적용
- 고덕 현장의 스마트폰 보행자·킥보드 적 스프라이트 로딩 수정
- 형사 맵의 배경이 위아래로 중복 표시되는 렌더링 문제 수정
- 이대리 진급 시 이과장으로 단일 교체하고 진급 능력치·장비 승계 적용
- 이과장 전체 모션 크기와 발 기준선을 통일하고 방어 프레임 배율 보정
- 완주 보상창과 프리미엄샵 UI 개선
- Google Play 상품 조회 뒤 구매창이 자동으로 이어지도록 결제 흐름 수정

- 대기·8프레임 이동·점프·피격·방어 모션 교체
- 1타 만년필 베기·2타 레이저 사격·3타 교차 필살 공격 적용
- 3타 프레임 혼입과 이펙트 잘림 수정
- 8등신 필살기 컷인과 전용 스킬명 적용
