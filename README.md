# 출근전쟁

모바일 테스트 APK 배포 저장소입니다.

## v1.60

- 회사원편 최신 맵·캐릭터 수정본 통합
- 남병장과 155mm 견인포 부대 챕터 1의 5개 맵 추가
- 군대편 일반 빌런 4종과 FM 재방열 포대장 보스 추가
- 군대편 배경·신규 지형·남병장 전체 모션을 Android APK에 포함
- 회사원편 기준으로 군대편 캐릭터 화면 비율 조정
- 미사용 구형 자산 제거와 WebP 변환으로 APK를 506.6MB에서 86.6MB로 경량화
- Android `versionCode 61` 적용

## v1.59

- 이대리 필살기를 청백색 초장거리 펜 블레이드와 문서벽 파쇄 연출로 교체
- 이과장 필살기를 검은 먹선과 적색 레이저가 교차하는 X 폭발 연출로 교체
- 신규 필살기 4프레임의 투명도·발 기준·모바일 패키징 검증

## v1.58

- 업데이트 확인 주소를 실제 GitHub 배포 저장소로 수정
- Android 앱 버전을 네이티브 빌드 정보에서 직접 읽도록 개선
- 기존 설치본도 업데이트를 받을 수 있도록 이전 릴리스 저장소에 호환 배포

## v1.57

- 앱 실행 즉시 5분 준비 타이머 시작
- 캐릭터 선택과 노선 선택 중에도 준비 시간이 연속 차감
- 첫 스테이지 진입 순간 출근 제한시간을 정확히 5분으로 초기화

## v1.56

- 회사원 노선 챕터 5~6과 시즌 1 완결 스토리 추가
- 이대리·이과장 SD 캐릭터의 이동·전투·필살기 모션 전면 교체
- 챕터 6 구조조정 빌런 4종과 최종 보스, 6개 신규 맵 추가
- Android `versionCode 57` 적용

## v1.55

- 회사원 노선 챕터 1~4의 최신 맵, 지형물, 빌런, 보스와 스토리 대사 통합
- 챕터 1~4 배경·전경 지형 PNG가 Android APK에 빠짐없이 포함되도록 패키징 수정
- Android `versionCode 56` 및 WebView 자산 캐시 번호 갱신

## v1.54

- 직급 선택 팝업을 제거하고 캐릭터를 누르면 회전문처럼 순환하는 선택 방식 적용
- 등록된 직급 캐릭터 수에 맞춰 회전 목록이 자동 확장되도록 개선

## v1.53

- 게임 화면 전체의 가운데점 문자를 제거하고 문구 구분 방식을 정리
- 일반 장비 상점을 부위별 탭으로 분리
- 프리미엄샵 상단 문구 겹침과 Google 계정 버튼·캐릭터 선택 효과 개선
- 메뉴 대기시간이 출근 제한시간에서 차감되지 않도록 수정

## v1.52

- 프리미엄샵을 한국어 중심의 차분한 색상과 균일한 간격으로 보정
- Google Play 상품 조회 실패 뒤에도 구매 버튼에서 다시 연결할 수 있도록 개선
- 이과장 HUD를 전용 일러스트 초상화로 교체
- 이대리·이과장 선택 시 정류장 캐릭터 이미지까지 함께 전환
- 직급 선택창 닫기 버튼을 텍스트로 변경

## v1.51

- 게임 재화 명칭과 단위를 `월급`·`원`으로 통일
- 프리미엄샵의 `월급 2배` 상품과 Google Play 결제 상품 등록 반영

## v1.50

- 모바일 프리미엄샵의 상품명·설명·가격·구매 문구 겹침 수정
- Google Play에 등록된 상품만 구매 버튼이 활성화되도록 안전 처리
- 이과장 HUD 초상화의 얼굴 잘림 수정
- 이과장 카드를 누르면 이대리·이과장 중 출근 형태를 선택하도록 개선
- 형사맵의 배경이 위아래로 중복 표시되는 문제 수정
- 고덕 현장의 투명 적 표시와 HP/SP 회복 장비 옵션 반영

## v1.49

- HP/SP 회복량 장비 옵션과 실제 휴식 회복 배율 적용
- 고덕 현장의 스마트폰 보행자·킥보드 적 스프라이트 로딩 수정
- 형사 맵의 배경이 위아래로 중복 표시되는 렌더링 문제 수정
- 이대리 진급 시 이과장으로 단일 교체하고 진급 능력치·장비 승계 적용
- 이과장 전체 모션 크기와 발 기준선을 통일하고 방어 프레임 배율 보정
- 완주 보상창과 프리미엄샵 UI 개선
- Google Play 상품 조회 뒤 구매창이 자동으로 이어지도록 결제 흐름 수정

- 이과장 무가방 외형을 전체 모션에 통일
- 오른손 만년필·왼손 레이저 포인터 무기 위치 고정
- 대기·8프레임 이동·점프·피격·방어 모션 교체
- 1타 만년필 베기·2타 레이저 사격·3타 교차 필살 공격 적용
- 3타 프레임 혼입과 이펙트 잘림 수정
