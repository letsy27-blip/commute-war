# 출근전쟁

모바일 테스트 APK 배포 저장소입니다.

## v1.71

- 맵 에디터에서 지형물을 직접 선택하고 Delete 후 범위를 지정해 실제 게임 맵에서 제거하는 기능 추가
- 충돌선·적·보스·지형 수정 결과를 공용 맵 데이터로 저장해 모바일 APK에 반영
- 프레임 검수표에 게임 적용 상태, 경계 잘림 확인, 선택 프레임 수정 요청 기능 추가
- 모든 캐릭터·빌런·보스 런타임 이미지를 `assets/actors`로 통합하고 폐기 자산 참조 제거
- 이대리 모션 크기와 무기 손 위치, 이과장 프레임 여백, 남병장 곡괭이 자세와 캐릭터 크기 정리
- 메인 메뉴 선택 글자 겹침과 간격, 캐릭터 선택 화면, 커스텀샵·프리미엄샵 레이아웃 개선
- 군부대 1·2·3장의 최신 맵과 빌런·보스를 연결하고 캐시된 이전 이미지가 표시되는 문제 수정
- 군부대 3장 누락 일반 빌런을 전투와 프레임 검수표에 연결하고 16프레임 경계 접촉 0 확인
- 군부대 4장 최신 6개 맵과 전경 지형을 게임·에디터 미리보기에 연결
- Android `versionCode 72` 적용

## v1.70

- 빌런 4종과 강대위 보스를 맨머리·대한민국 육군식 계급표시·고정 무기 구성으로 새로 제작
- 대기·이동·공격·피격/패배 4×4 시트 80프레임의 잘림·빈 셀·프레임 혼입 검사 통과
- 탄약 불출장·탄약고·작전과 사무실·지휘통제실 전경 지형과 보스 장비 이미지 추가
- Android `versionCode 71` 적용

## v1.69

- 군부대 1장 빌런·포대장 프레임을 확장해 무기·헬멧·결재판·공격 이펙트 잘림 제거
